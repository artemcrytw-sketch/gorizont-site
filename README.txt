САЙТ «ГОРИЗОНТ» — ИНСТРУКЦИЯ

1. Распакуйте архив в отдельную папку.
2. Откройте index.html двойным щелчком — сайт запустится в браузере.
3. Все страницы связаны меню. Для работы сайта не нужно устанавливать программы.
4. Не удаляйте папки css, img и docs: они содержат стили, изображения и документы.
5. Для публикации в интернете загрузите ВСЕ содержимое папки gorizont_site на хостинг статических сайтов (например, GitHub Pages или Netlify).

Страницы:
- index.html — главная
- destinations.html — направления
- tips.html — советы
- gallery.html — галерея и файлы
- css/style.css — единая внешняя таблица стилей

Проверка требований:
- 4 страницы и единое меню: выполнено
- внешний CSS: css/style.css подключён ко всем страницам
- логотип-ссылка на главную: слева вверху каждой страницы
- анимация: CSS-анимация появления и эффекты наведения
- файлы PDF, DOCX, XLSX, JPG: gallery.html
- изображение слева и текст справа: destinations.html и tips.html
- alt у изображений: добавлен
- фоновое изображение: блок на главной странице, CSS background-image

Тема и текст развивают исходный сайт пользователя о путешествиях.
